# 单位约定与配置换算规则

## 1. 内部统一 SI 合同

| 物理量 | 内部单位 | 说明 |
|---|---|---|
| 数据量、缓存占用与容量 | bit | `D_in,D_out,s,S_max` |
| 带宽 | Hz | `B_u,B_d` |
| 数据速率 | bit/s | `R_u,R_d,R_bh` |
| 计算频率/算力 | cycle/s | `F_L,f,f_min^E,f_max^E,F_max` |
| CPU 计算量 | cycle | `C` |
| 功率、干扰、噪声功率 | W | `P_u,P_d,P_r,I_u,I_d,σ²` |
| 信道功率增益 | 线性无量纲值 | `h_u,h_d`；不得把 dB 值直接代入香农公式 |
| 时延 | s | `T,τ,T_dep` |
| 能耗 | J | `E` |
| 标准化扰动、`Γ`、`η` | 无量纲 | `z,Γ,η` |

`κ_n` 必须与 `E=κCF²` 的 SI 口径相容；若 `C` 用 cycle、`F` 用 cycle/s、`E` 用 J，则其量纲应与 `J·s²/cycle³` 相容。配置中必须注明来源单位，不得猜测。

## 2. 工程单位到 SI 的显式换算

### 数据量

```text
bit  → bit: ×1
kbit → bit: ×10³
Mbit → bit: ×10⁶
Gbit → bit: ×10⁹
byte → bit: ×8
kB   → bit: ×8×10³
MB   → bit: ×8×10⁶
GB   → bit: ×8×10⁹
KiB  → bit: ×8×2¹⁰
MiB  → bit: ×8×2²⁰
GiB  → bit: ×8×2³⁰
```

禁止使用含义不明的 `K/M/G` 或大小写混乱的 `kb/KB`。配置必须写完整单位标识。

### 带宽与速率

```text
kHz/MHz/GHz → Hz: ×10³/10⁶/10⁹
kbit/s, Mbit/s, Gbit/s → bit/s: ×10³/10⁶/10⁹
```

### 计算量与计算频率

```text
kcycle/Mcycle/Gcycle → cycle: ×10³/10⁶/10⁹
kcycle/s, Mcycle/s, Gcycle/s → cycle/s: ×10³/10⁶/10⁹
```

若来源把 CPU 频率写作 kHz/MHz/GHz，只有在模型明确“一周期对应一 cycle/s”口径时才能按同倍数转换为 cycle/s，并在配置元数据中记录该假设。

### 功率、干扰与噪声

```text
mW/µW/nW → W: ×10⁻³/10⁻⁶/10⁻⁹
dBm → W: 10^((dBm-30)/10)
```

`σ²` 在模型入口必须是给定带宽上的总噪声功率 W。若来源给的是噪声功率谱密度 `W/Hz` 或 `dBm/Hz`，必须先结合明确带宽计算总噪声功率，不能直接代入。

### 信道功率增益

```text
功率增益 dB → 线性值: 10^(gain_dB/10)
```

若来源给的是幅度增益，不能沿用功率增益换算；必须先确认物理含义。

### 时延与能耗

```text
ms/µs/ns → s: ×10⁻³/10⁻⁶/10⁻⁹
mJ/µJ/nJ → J: ×10⁻³/10⁻⁶/10⁻⁹
```

## 3. 配置加载边界规则

1. 原始配置值必须与单位字段成对出现，或由带单位的字段名明确表达；裸数不得依靠隐式默认工程单位。
2. 单位转换只发生在配置加载阶段；物理模型、求界器、数据集、BP、优化器和认证器只接收 SI。
3. 区间上下端点必须使用同一源单位转换，并在转换后检查有限性、非负性及 `lower≤upper`。
4. 转换结果与原始值、原始单位、SI值、转换因子均应进入可追溯配置快照。
5. 禁止在公式函数内部重复换算，避免二次缩放。
6. 对 dB/dBm、Byte/bit、十进制/二进制前缀执行强校验；不明确时拒绝加载。

## 4. 量纲验收

- `R=B log2(1+SINR)` 输出 bit/s。
- `D/R`、`C/f`、`s/R_bh` 输出 s。
- `P·D/R` 输出 J。
- `κCF²` 输出 J。
- 系统聚合前各用户量必须使用同一 SI 单位。
