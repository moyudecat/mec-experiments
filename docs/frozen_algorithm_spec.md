# 第四章冻结算法规范

> 当前主要论文依据：`reference_docs/第四章_双BP误差修正_校订三线表版.docx`。2026-08-10 已通过共享只读OOXML同步4.2、4.3及在线评价规则；Word因外部占用未导出视觉副本，原文件未修改。本文件不冻结留待 Preview 确定的网络与训练数值超参数。

## 1. 总体流程

算法采用三阶段框架：离线真实模型标注、双 BP 训练与独立误差校准、在线修正双 BP 代理评价。可解析项保持解析处理，只有预算不确定性耦合下的边缘核心时延和终端通信能耗边界进入代理。正式在线优化不执行搜索后真实模型认证。

## 2. 离线边界样本生成

- 在预先冻结的合法参数域内用普通 LHS 生成用户级输入。
- Train、Validation、Calibration、Test及生成种子互斥，完全重复和尺度归一近重复输入不得跨集合。
- 每个样本由真实物理模型与内层 GA 标注，禁止用 BP 产生标签。
- 对输入合法性、边界顺序、响应非负、近重复和多种子稳定性做质量控制。
- 随机抽样以更高预算 GA 或高密度可行 LHS 复核；不稳定样本提高预算后重标，未通过者不进入训练集。

## 3. 内层 GA 的四类边界任务

对每个用户级输入分别求：

1. 边缘核心时延下界；
2. 边缘核心时延上界；
3. 终端通信能耗下界；
4. 终端通信能耗上界。

染色体为实数扰动向量。时延使用前五个有效分量，能耗使用 `D_in,D_out,I_u,I_d` 四个分量，其他分量固定为零。初始化混合可行 LHS、标称点和预算边界特征点；优先拒绝采样，遗传操作后的不可行个体先裁剪再按比例投影：

```text
z_n ← z_n min(1, Γ/Σ_k|z_{n,k}|)
```

GA 使用锦标赛选择、连续交叉、连续变异和精英保留。上界最大化 `q`，下界通过最大化 `-q` 统一选择逻辑。多随机种子重复后，上界取最大、下界取最小。结果是近似极值，不是全局最优证明。

## 4. 时延 BP

- 输入：`f_n`；`D_in,D_out,C,I_u,I_d` 的区间端点；与时延公式有关的带宽、信道、通信功率、噪声等确定特征；正式模型必须包含 `Γ`。
- 输出：边缘核心时延中心 `T_n^{E,c}` 与半径 `T_n^{E,r}`。
- 标签：真实物理模型与内层 GA 得到的核心时延上下界转换成中心—半径；不含缓存未命中项。
- 所有用户共享同一组时延网络参数。

## 5. 能耗 BP

- 输入：`D_in,D_out,I_u,I_d` 区间端点及相关无线功率特征；正式模型必须包含 `Γ`。
- 不输入：`C_n,f_n,c_n`。
- 输出：终端通信能耗中心 `E_n^{E,c}` 与半径 `E_n^{E,r}`。
- 标签：真实物理模型与内层 GA 得到的通信能耗上下界转换成中心—半径。
- 所有用户共享同一组能耗网络参数。

## 6. 中心—半径输出机制

输入用训练集统计量做零均值标准化。中心与半径标签共享同一个正值尺度 `s_q`。网络原始输出 `a_c,a_r` 经：

```text
q̂^r=softplus(a_r)
q̂^c=q̂^r+softplus(a_c)
q^c=s_q q̂^c, q^r=s_q q̂^r
q^-=q^c-q^r, q^+=q^c+q^r
```

从结构上保证 `0≤q^-≤q^+`。训练集统计量冻结后用于验证、测试和在线阶段。

## 7. 损失与时延上界低估

一般回归损失在恢复物理尺度后计算中心、半径、下界和上界的均方误差加权和：

```text
L_base=α_c E_c+α_r E_r+α_L E_L+α_U E_U
```

时延网络额外使用：

```text
L_T=L_base+α_u mean(max(0,T_i^U-T̂_i^U)^2)+λ||θ_T||²
```

主方案不按“核心时延上界距 `τ_n`”直接加权，因为完整时延还依赖未进入网络输入的缓存状态。能耗网络采用一般回归损失与正则项。

## 8. 在线本地确定性求界与缓存补充

- `m_n=0,Γ=0`：直接计算 `C,F_L` 中心点，区间退化为点值。
- `m_n=0,0<Γ<2`：在只含 `C,F_L` 的二维预算域内执行确定性求界；利用单调性和有限分段/边界候选，不调用 BP 或 GA。
- `m_n=0,Γ≥2`：使用第三章闭式边界，不调用 BP 或 GA。
- `m_n=1`：双 BP 分别恢复 `edge_core_latency_*` 和 `edge_comm_energy_*` 区间。
- 缓存未命中时延 `(1-c_n)T_n^dep` 解析地同加到 core 上下界形成 `edge_total_latency_*`，不进入 BP。系统聚合和 C7 只能使用 total。

## 9. C1—C6 统一修复

1. 二元变量裁剪；执行 `c_n←c_n m_n`，本地任务令 `f_n←0`。
2. 缓存超容时，按确定性缓存收益密度 `π_n^cache=T_n^dep/s_n` 从低到高取消缓存；不使用 BP 目标。
3. 若全部边缘用户的最小算力总需求超过容量，按标称环境下单位最小算力时延改善 `ρ_n^f=ΔT_n^nom/f_min^E` 从高到低保留可支持的最大用户数，其余改为本地，并同步清零 `m,c,f`。
4. 可行边缘用户先分配 `f_min^E`，剩余算力按连续基因非负权重迭代分配；达到 `f_max^E` 后在未饱和用户间重分配。
5. 并列时依次按用户编号和决策哈希排序。所有算法共享修复器、标称环境、指标和并列规则。

## 10. C7 显式计算

从用户时延区间按第三章可能度公式计算 `Pos`，在线总违反度为：

```text
CV_pred(x)=Σ_n max(0,η-Pos{T_n^pred(x)≤τ_n})
```

不训练第三个网络。正式在线可行性直接使用经冻结 alpha 修正并叠加缓存解析项后的 `corr_pred` 完整时延区间计算。

## 11. 外层约束 NSGA-II

- 个体为混合编码 `x=(m,c,f)`；二进制变量使用均匀交叉与比特翻转，连续变量使用连续交叉与多项式变异。
- 子代评价前统一修复 C1—C6。
- 采用 Deb 约束支配：可行优于不可行；均不可行时较小 `CV` 优先；均可行时按两目标 Pareto 支配。
- 使用快速非支配排序、目标归一化拥挤距离及父子代合并环境选择。
- 维护修正预测可行非支配档案、近可行档案和当前种群；全部排序和约束评价使用同一 `corr_pred` 口径。

## 12. 字段口径与离线误差校准

- `ga_ref_*`：仅用于离线标注、Calibration和预注册的独立误差实验；其值来自 `Adaptive-B4-Reference-v1` 高保真近似标签。
- `raw_pred_*`：冻结BP未经alpha修正的输出。
- `corr_pred_*`：使用独立Calibration角色冻结的四类alpha进行保守修正后的正式在线评价结果。
- `final_*`：从 `corr_pred` 可行Rank-1前沿按冻结理想点距离和并列规则选出的代表方案。
- Calibration不得训练网络权重；Test不得选择网络、loss、alpha或数据划分。本轮数据协议只预留alpha字段，不计算数值。

## 13. 修正预测前沿与最终代表方案

- 正式在线搜索的支配、约束、档案和最终前沿均使用 `corr_pred_*`。
- 对修正预测可行Rank-1前沿的两目标做冻结的最小—最大归一化和零极差处理，计算等权理想点距离。
- 距离最小者写入 `final_*`；并列时依次比较最小QoS裕量、最大归一化目标和决策哈希。
- 不建立五候选池，不运行搜索后GA认证，不生成 `certified_*`，不以离线GA参考替换最终方案。

## 14. 评价与表述边界

- `ga_ref_*` 只能称高保真近似标签或经验参考，不称数学精确边界。
- `raw_pred_*` 用于原始代理精度评价；`corr_pred_*` 用于正式在线搜索与安全性评价；`final_*` 用于最终代表方案。
- 所有算法内部物理量采用 `unit_convention.md` 的 SI 单位；单位转换只允许发生在配置加载阶段。
- 网络结构、BP 损失权重、校准分位、alpha和外层预算继续留待对应 Preview 冻结，本文件不赋值。
