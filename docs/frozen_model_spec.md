# 第三章冻结模型规范

> 主要论文依据：`reference_docs/第三章_冻结模型.docx`。2026-08-03 第一批实现口径冻结对 `Γ<2` 本地求界、代码命名和 SI 单位作了补充决定，详见 `decision_log.md`；这些决定尚待同步到 Word。带上下划线的量分别表示区间下、上界；`c`、`r` 上标表示中心、半径。

## 1. 系统场景与基本假设

- 系统由移动终端、边缘服务器和远端云平台组成，用户集合为 `𝒩={1,2,…,N}`。
- 每个用户产生一个不可分割任务，仅可本地执行或边缘执行；云平台只在缓存未命中时提供依赖资源回源，不是任务执行位置。
- 研究单个调度周期，不考虑预缓存及缓存跨周期演化。
- 用户采用正交无线接入，上下行带宽预分配且固定；区间干扰表示外部同频干扰、背景业务和传播环境变化，不显式建模用户间瞬时干扰耦合。
- 各用户拥有独立的任务级预算不确定集合。给定外层决策后，用户响应只依赖自身扰动，因此系统响应边界可按用户边界求和。
- 系统能耗口径仅为移动终端侧累计能耗，不计边缘服务器功耗、基站发射能耗、边云回传能耗。

用户任务参数向量为 `θ_n=(D_n^in,D_n^out,C_n,s_n,τ_n)`，其中前三项为区间参数，`s_n` 为依赖资源缓存占用量，`τ_n` 为最大容忍时延。

## 2. 决策变量

- 卸载：`m_n∈{0,1}`。`m_n=0` 表示本地，`m_n=1` 表示边缘；`m=(m_1,…,m_N)`。
- 缓存：`c_n∈{0,1}`，且 `c_n≤m_n`；`c=(c_1,…,c_N)`。
- 边缘算力：`m_n f_min^E≤f_n≤m_n f_max^E`，且 `Σ_n f_n≤F_max`；`f=(f_1,…,f_N)`。
- 联合方案：`x=(m,c,f)`。

## 3. 六类区间不确定参数

对每个用户，区间参数为：

1. `D_n^in`：任务输入数据量；
2. `D_n^out`：任务输出数据量；
3. `C_n`：任务所需 CPU 周期数；
4. `I_n^u`：上行干扰功率；
5. `I_n^d`：下行干扰功率；
6. `F_n^L`：终端本地可用计算频率。

## 4. 区间中心、半径与标准化扰动

任意 `p_j∈[p̲_j,p̄_j]`：

```text
p_j^c = (p̲_j+p̄_j)/2
p_j^r = (p̄_j-p̲_j)/2
p_j   = p_j^c+p_j^r z_j,  -1≤z_j≤1
```

用户扰动 `z_n=(z_{n,1},…,z_{n,6})^T`，系统扰动 `z=(z_1^T,…,z_N^T)^T`。

## 5. Γ 预算不确定集合

任务级集合：

```text
𝒰_{Γ,n}={z_n∈[-1,1]^6 : Σ_{k=1}^6 |z_{n,k}|≤Γ},  0≤Γ≤6
𝒰_Γ=∏_{n∈𝒩}𝒰_{Γ,n}
```

`Γ` 是确定性预算参数，不是区间变量；数值越大，允许的联合偏移越强、边界通常越保守。

## 6. 上下行香农速率

设上下行带宽为 `B_n^u,B_n^d`，信道功率增益为 `h_n^u,h_n^d`，终端上行发射功率为 `P_n^u`，基站下行发射功率为 `P_n^d`，终端接收功率为 `P_n^r`，噪声功率为 `σ²`：

```text
R_n^u(I_n^u)=B_n^u log2(1+P_n^u h_n^u/(σ²+I_n^u))
R_n^d(I_n^d)=B_n^d log2(1+P_n^d h_n^d/(σ²+I_n^d))
```

速率关于干扰单调递减，因此最小速率取干扰上界，最大速率取干扰下界。第三章同时给出盒式区间下各传输分量的边际包络，但明确说明预算约束下不能把各分量最坏端点直接相加。

## 7. 本地时延与能耗

点响应：

```text
T_n^L(z_n)=C_n(z_n)/F_n^L(z_n)
E_n^L(z_n)=κ_n C_n(z_n)[F_n^L(z_n)]²
```

普适边界为上述响应在 `𝒰_{Γ,n}` 上的最小值和最大值。第一批实现口径冻结后，统一采用以下确定性分段协议，所有分支均不调用 BP 或 GA：

1. `Γ=0`：`C_n=C_n^c,F_n^L=F_n^{L,c}`，直接计算中心点，四个区间端点均退化为相应点响应。
2. `0<Γ<2`：仅保留 `C_n,F_n^L` 两个有效扰动，在二维集合 `|z_C|≤1,|z_F|≤1,|z_C|+|z_F|≤Γ` 内对本地时延和能耗做确定性求界。求界器必须利用明确的单调性和有限分段/边界候选解析处理，不调用随机搜索、GA 或 BP。
3. `Γ≥2`：两个有效分量可同时到达所需端点，使用第三章闭式边界：

```text
T̲_n^L=C̲_n/F̄_n^L        T̄_n^L=C̄_n/F̲_n^L
E̲_n^L=κ_n C̲_n(F̲_n^L)²  Ē_n^L=κ_n C̄_n(F̄_n^L)²
```

`0<Γ<2` 不得直接使用闭式特例。该分段协议保留第五章 S1 和 Exp-5 中的 `Γ=1`；第三、四章 Word 正文尚待同步。

## 8. 边缘执行时延

缓存未命中回源时延：

```text
T_n^dep=s_n/R^bh
```

不含回源项的核心时延（代码语义 `edge_core_*`，作为时延 BP 标签）：

```text
T̃_n^E(x,z_n)=D_n^in(z_n)/R_n^u(z_n)+C_n(z_n)/f_n+D_n^out(z_n)/R_n^d(z_n)
```

完整边缘时延（代码语义 `edge_total_*`，用于系统聚合和 C7）：

```text
T_n^E(x,z_n)=T̃_n^E(x,z_n)+(1-c_n)T_n^dep
```

核心时延上下界是在 `𝒰_{Γ,n}` 上对 `T̃_n^E` 求最小值和最大值；缓存未命中项是确定量，求界后同加到上下界。严禁用 `edge_total_*` 训练时延 BP，也严禁用 `edge_core_*` 直接进行系统聚合或 C7 判定。

## 9. 移动终端通信能耗

```text
E_n^{E,x}(z_n)=P_n^u D_n^in(z_n)/R_n^u(z_n)+P_n^r D_n^out(z_n)/R_n^d(z_n)
```

边缘执行终端能耗上下界是在 `𝒰_{Γ,n}` 上求最小值和最大值。该公式不依赖 `C_n`、`f_n`、`c_n`，也不包含基站下行发射能耗。

## 10. 用户与系统区间聚合

用户统一边界：

```text
T̲_n=(1-m_n)T̲_n^L+m_n T̲_n^E    T̄_n=(1-m_n)T̄_n^L+m_n T̄_n^E
E̲_n=(1-m_n)E̲_n^L+m_n E̲_n^E    Ē_n=(1-m_n)Ē_n^L+m_n Ē_n^E
```

系统累计边界：

```text
T̲_Σ=Σ_n T̲_n   T̄_Σ=Σ_n T̄_n
E̲_Σ=Σ_n E̲_n   Ē_Σ=Σ_n Ē_n
```

系统中心与半径分别为 `(下界+上界)/2` 和 `(上界-下界)/2`。该精确求和依赖正交接入、用户预算独立和响应可加和。

## 11. 两个鲁棒目标

```text
Φ_T(x)=arctan(T_Σ^c/ρ_T)+λ_T arctan(T_Σ^r/ρ_T)
Φ_E(x)=arctan(E_Σ^c/ρ_E)+λ_E arctan(E_Σ^r/ρ_E)
```

其中 `ρ_T,ρ_E>0`，`λ_T,λ_E≥0`。优化问题为最小化 `(Φ_T,Φ_E)^T`。

## 12. C1—C7

```text
C1: m_n∈{0,1}
C2: c_n∈{0,1}
C3: c_n≤m_n
C4: Σ_n c_n s_n≤S_max
C5: m_n f_min^E≤f_n≤m_n f_max^E
C6: Σ_n f_n≤F_max
C7: Pos{[T̲_n(x),T̄_n(x)]≤τ_n}≥η
```

C1—C3、C5、C7 对每个用户成立。C1—C6 是确定性约束；C7 从时延区间显式计算。

## 13. C7 可能度

```text
Pos{[T̲_n,T̄_n]≤τ_n} = 1,                         T̄_n≤τ_n
                       (τ_n-T̲_n)/(T̄_n-T̲_n),    T̲_n<τ_n<T̄_n
                       0,                         τ_n≤T̲_n
```

区间退化为单点时按确定性条件判断。`η∈[0,1]`。用户缺口 `v_n=max(0,η-Pos_n)`，总违反度 `CV(x)=Σ_n v_n`。可能度不是频率概率。

## 14. 变量、单位、域与依赖

| 符号 | 含义 | 域/单位（原文明确程度） | 主要依赖或影响 |
|---|---|---|---|
| `N,𝒩` | 用户数、集合 | 正整数、索引集合 | 系统规模 |
| `m_n,c_n` | 卸载、缓存 | `{0,1}` | 执行路径、回源项 |
| `f_n` | 边缘分配频率 | `[0,f_max^E]`；内部 `cycle/s` | 边缘计算时延 |
| `D_n^in,D_n^out` | 输入/输出量 | 非负区间；内部 `bit` | 通信时延、终端通信能耗 |
| `C_n` | CPU 周期数 | 非负区间；内部 `cycle` | 本地开销、边缘计算时延 |
| `I_n^u,I_n^d` | 干扰功率 | 非负区间；内部 `W` | 上下行速率 |
| `F_n^L` | 本地可用频率 | 正区间；内部 `cycle/s` | 本地时延与能耗 |
| `s_n,S_max` | 依赖占用、缓存容量 | 非负；内部 `bit` | C4、回源时延 |
| `τ_n` | 最大容忍时延 | 正值；内部 `s` | C7 |
| `Γ` | 任务级预算 | `[0,6]`，无量纲 | 扰动集合 |
| `z_{n,k}` | 标准化扰动 | `[-1,1]`，且绝对值和受预算约束 | 恢复实际区间参数 |
| `B_n^u,B_n^d` | 上下行带宽 | 正值；内部 `Hz` | 香农速率 |
| `h_n^u,h_n^d` | 信道功率增益 | 非负；内部线性无量纲值 | 香农速率 |
| `P_n^u,P_n^d,P_n^r` | 上行发射、下行发射、终端接收功率 | 非负；内部 `W` | 速率或终端通信能耗 |
| `σ²` | 噪声功率 | 非负；内部 `W` | 香农速率 |
| `κ_n` | 有效开关电容系数 | 非负；须与 `E=κCF²` 的 SI 量纲相容 | 本地能耗 |
| `R^bh` | 边缘—云回传速率 | 正值；内部 `bit/s` | 缓存未命中时延 |
| `f_min^E,f_max^E,F_max` | 算力下限、单用户上限、总容量 | `f_min^E>0`；内部 `cycle/s` | C5、C6 |
| `ρ_T,ρ_E` | 目标尺度 | 正值；分别与时延、能耗同量纲 | 鲁棒目标归一尺度 |
| `λ_T,λ_E` | 半径惩罚 | 非负、无量纲 | 鲁棒目标 |
| `η` | 可能度阈值 | `[0,1]`，无量纲 | C7 |

所有物理模型内部统一使用 `bit,Hz,bit/s,cycle/s,cycle,W,线性信道增益,s,J`。工程单位只允许在配置加载阶段按 `unit_convention.md` 显式转换。具体参数数值及其文献/实验来源仍记录在 `unresolved_questions.md`，本轮不作推断。
